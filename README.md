This is a small Python program that writes one short text for make.fun's bounty `u-gudril-cool-two-lines-of-morning-light-ade94fc5`: a two-line micro poem about light and morning, held as a single string constant and written byte for byte, with no trailing newline, into the folder named by `MAKEFUN_OUTPUT_DIR` (falling back to `/output`), printing the character count to stderr.

```text
The cat has not moved since six.
The square of light has, and takes her with it.
```

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
